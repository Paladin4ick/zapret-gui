## 🛡️ О проекте

**zapret GUI** — это удобная графическая обёртка для оригинального проекта [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube), позволяющая управлять zapret в Windows без работы с командной строкой.

[![Скачать последнюю версию](https://img.shields.io/badge/Скачать-последнюю_версию-A6192E?style=for-the-badge&logo=github)](https://github.com/Paladin4ick/zapret-gui/releases/latest)

> [!IMPORTANT]
> Приложение не является VPN и не перенаправляет трафик через сторонние серверы. Для работы WinDivert требуются права администратора.

## 🙌 Благодарности
