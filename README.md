# zapret GUI

Легковесная графическая оболочка для Windows над
[zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) от Flowseal.
Приложение не является VPN и не устанавливает zapret как постоянную службу Windows.

## Возможности

- автоматическая загрузка и обновление официальных релизов Flowseal;
- динамическое обнаружение стратегий из локальной папки `zapret`;
- запуск и остановка zapret из окна и системного трея;
- автоподбор через оригинальный `utils/test zapret.ps1` с прогрессом и отменой;
- редактирование пользовательских списков и просмотр системных списков;
- настройки Game Filter, IPSet, автозапуска и обновлений;
- сохранение пользовательских файлов при обновлении и резервная копия предыдущей версии;
- компактный интерфейс Rust + Slint с поддержкой DPI.

## Использование

1. Скачайте `zapret-gui.exe` из GitHub Releases или артефактов Actions.
2. Поместите файл в отдельную папку с правом записи и запустите его.
3. Подтвердите запрос прав администратора, необходимый WinDivert.
4. При первом запуске дождитесь загрузки файлов Flowseal.
5. Выберите стратегию и нажмите круглую кнопку питания.

Рядом с EXE автоматически появятся папка `zapret/`, файл `zapret-gui.json` и резервные
копии предыдущих версий. Пользовательские списки `*-user.txt` сохраняются при обновлении.

## Разработка

Требуется стабильный Rust. Основные команды:

```powershell
cargo fmt --all -- --check
cargo clippy --all-targets -- -D warnings
cargo test
cargo build --release
```

Собранный файл находится в `target/release/zapret-gui.exe`.

## Ограничения

- Запуск и проверка работы WinDivert доступны только на Windows с правами администратора.
- Автоподбор требует `curl.exe`, PowerShell и сетевой доступ к целям теста Flowseal.
- Антивирус может предупреждать о WinDivert/winws — эти файлы загружаются из официального
  релиза Flowseal, а доступный SHA-256 релизного файла проверяется перед установкой.
